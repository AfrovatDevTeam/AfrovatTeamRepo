THEORY QUESTIONS


1. What is an array?


An array is a collection of values stored in a single variable.
It can store multiple values of the same data type, and each value is stored at a specific position called an index.







2. What does numbers[0] mean?


numbers[0] means the first value stored in the array.

numbers = array name

[0] = index position

Index 0 refers to the first element






3. Why does an array start at index 0?


Arrays start at index 0 because that is how programming languages are designed.

Index 0 represents the first memory location, index 1 is the second, and so on.





4. What happens if you try to access numbers[5] in a 5-element array?



You will get an error called: Index Out of Range Exception

Because a 5-element array only has indexes:0, 1, 2, 3, 4





5. What is the difference between a variable and an array?

Variable:

Stores one value

Array:

Stores multiple values
